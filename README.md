## Featured projects

### [Dayflow](https://github.com/Farhan-Mansoor74/dayflow)
An installable personal organizer for tasks, reminders, expenses, and a password vault, with a desktop dashboard, spending charts by category, and a read-only offline mode. Security-focused throughout: Google sign-in with server-side sessions in HttpOnly cookies, vault entries encrypted per user with AES-256-GCM and unlocked by face recognition or an emailed code, shared rate limits, and a strict Content Security Policy. Reminders arrive by web push or email, scheduled with QStash. Built with a React-based PWA, Node.js, Express, and PostgreSQL; deployed on Vercel.

[Live app](https://dayflow-drab-chi.vercel.app) (private: sign-in is limited to invited accounts)

### [Fixora Home Services](https://github.com/Farhan-Mansoor74/maintenance-service-website)
A home-maintenance portfolio app with guided enquiries, private photo uploads, technician management, appointment scheduling, and automated email delivery. Built with Next.js, React, TypeScript, Supabase, and n8n; deployed on Vercel.
